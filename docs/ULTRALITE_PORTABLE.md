# SteamUltraLite — portable-сборка Windows x64

Распакуйте архив в отдельную папку и запустите `steam-ultralite.exe`.
Установленный Rust, Python и официальный клиент Steam для открытия окна не нужны.
Для игр, которым требуются Steamworks, DRM или античит, кнопка запуска откроет
официальный Steam. Прямой запуск проверен только для AppID 3048420 и 757170.

Добавьте существующие папки Steam через «Установленные» → «Обзор…».
Для входа используйте QR-код Steam Guard. Не вводите пароль в сторонние окна.
Steam Cloud проверяется и синхронизируется вручную; перед отправкой и загрузкой
проверяйте счётчики. При конфликте клиент не перезаписывает сохранения.

Это переносимая программа, но настройки папок и снимки Cloud хранятся в
`%LOCALAPPDATA%\SteamUltraLite`, а сохранённый вход — в Windows Credential
Manager текущего пользователя. Архив не переносит эти данные между ПК.

Клиент неофициальный и не связан с Valve. Файл не подписан цифровой подписью.
Проверяйте `SHA256SUMS.txt` перед запуском. При предупреждении антивируса
сохраните отчёт и проверьте файл; защиту отключать не требуется.

Исходники и сведения о лицензии: https://github.com/total911/SteamUltraLite
