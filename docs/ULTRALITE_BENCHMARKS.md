# Этап 5. Замеры релизных сборок

Windows 11 Pro (26200), Ryzen 5 3600 (6 ядер, 12 потоков), 32 ГиБ RAM.
База — SteamInRust 0.15.0, `abe8275`, с исправленным upstream lockfile
`401bf66`. Исходники базовой сборки соответствуют тегу.
[Подробности сборки](ULTRALITE_BASELINE.md).

## Методика

Обе релизные сборки запускались с диска E: по очереди. Порядок менялся
в каждой паре. Каждый прогон создавал новый процесс, системный файловый
кэш не очищался. Использовались один демонстрационный аккаунт и одна
локальная библиотека из 1009 синтетических манифестов и одного ярлыка
сторонней игры. Оба окна имели размер 1060 × 700 пикселей. Флаги:
`--demo --no-local --offscreen --separate --page=library --lang=en
--window-size=1247x824 --demo-library=<путь-к-фикстуре>`. Размер во флаге
компенсирует масштаб 0,85 базового клиента.

Отсчёт шёл от запуска процесса по монотонному таймеру. Готовность окна
определялась по появлению основного окна с ожидаемым заголовком, готовность
списка — по совпадению пикселей текста строки `Bench Game 0001` с отдельным
эталоном каждой сборки. Снимок окна делался через Windows `PrintWindow`.

После 60 с покоя снимались `PrivateMemorySize64` и `WorkingSet64`.
CPU — прирост `TotalProcessorTime` за последние 20 с, делённый на
фактическую длительность интервала. Число процессов считалось по дереву
`Win32_Process`. 1 МБ = 1 000 000 байт. В сравнении размера участвуют
одинаковые файлы обеих сборок. Размер DLL i686 вынесен в
[отчёт сборки](ULTRALITE_BUILD.md).
[Определение private bytes в .NET](https://learn.microsoft.com/en-us/dotnet/api/system.diagnostics.process.privatememorysize64).
