Проверен коммит `a8b9356` с обновлением плана `f381bb6` на Windows 11 Pro
(сборка 26200), Ryzen 5 3600, 12 потоков. Релиз собран командой
`cargo build --locked --offline --release -p steam-ultralite` с MSYS2 MinGW64
на диске E:. EXE: 9 960 448 байт; SHA-256
`1e4b3a4b65948ae6c95dbe6b6d7974901462c0c098c6fde83013548c82d08645`.

## Пять запусков

Один и тот же EXE запускался по очереди без входа в Steam, с локальной
библиотекой `D:\Games`. Каждый прогон создавал новый процесс; системный
файловый кеш не очищался. После 60 секунд покоя снимались private bytes и
рабочий набор. CPU измерялся за следующие 20 секунд как доля одного ядра.
Число процессов включает прямых потомков. Отдельная серия измеряла время
от запуска до окна и до первой строки списка `Alchemyland`: готовность
строки определялась точным совпадением пикселей области строки с эталоном

## Состав и проверка

`cargo tree --locked --offline -p steam-ultralite --edges normal` не содержит
старый `client`, `steam-rs`, `steamclient`, `wgpu`, WebView, `tauri`, `rhai`,
`str0m`, `opusic-sys` и `tray-icon`. PE-импорт EXE содержит только системные
DLL Windows; дополнительные DLL в архиве не нужны.

Kaspersky 21.27 проверил итоговый EXE с базами от 28.11.2026: 1 объект,
0 обнаружений, 0 подозрений, 0 пропусков и 0 ошибок. Пять измерительных
запусков не были остановлены антивирусом. Это проверка данного файла,
а не гарантия будущих сигнатур. EXE не имеет цифровой подписи.

Архив `E:\SteamUltraLite-build\rewrite-stage6\SteamUltraLite-win64.zip`
содержит только EXE, `LICENSE`, `README.md` и `SHA256SUMS.txt`. Размер
4 652 347 байт; SHA-256
`196907938f4ca07289b16b4897119c6978f26d19ae3653ed3bd6cb0aa077ac1d`.
После распаковки хеши всех трёх файлов совпали с `SHA256SUMS.txt`.
Распакованный EXE открыл окно и после окончания начальной загрузки
закрылся штатно с кодом 0. Чистый ПК без системных компонентов Steam
для игр, которым требуется официальный клиент, отдельно не проверен.

Функциональные проверки входа, установки, запуска и Cloud перечислены в
[плане](ULTRALITE_PLAN.md). Для Cloud проверены скачивание и отправка по
одному файлу, конфликт без перезаписи и возврат счётчиков к нулю.
